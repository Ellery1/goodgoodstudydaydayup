# 《以我见人：从生活到素材的记叙文写作》方案

## 一、背景与方向

现有的《以人证道》以人物素材服务议论文和半命题作文，逻辑是"题目 → 标签 → 人物"，用别人的故事证明一个观点。

六七年级的考试以记叙文为主（八年级起转向议论文），题目多围绕"自己"的生活，比如"一次有趣的尝试"。学生的问题通常不是没有经历，而是写出来像流水账。

本书的方向：记叙文以"我"的经历为线，但要尽量多用人物素材。素材通过真实的生活入口进入文章，比如扫墓、参观、读书、家里的一件东西。这样既不生硬，又能体现学生的知识面，形成得分点。素材库中于谦祠、鲁迅墓两段就是这种写法。

目标读者为六、七年级学生，完整范文按 600 字左右写。

所有范文、示范段落都必须遵守 [写作规范](写作规范.md)。

## 二、产出形式与文件组织

**独立成书，与《以人证道》共用同一份人物素材。** 新书正文全部写成 md，方便手动修改，再由 build_book.py 生成 HTML。

### 文件结构

```
chinese-essay-figures/figures/          人物素材，两本书共用，只有这一份
narrative-writing-guide/
├── 方案.md、写作规范.md                 内部文档，不进入成书
└── book/
    ├── 前言.md
    ├── 写法/01-动词写人.md ……            文件名前的序号决定顺序
    ├── 题型/01-成长.md ……
    └── 素材入文/01-示范段落.md、02-生活入口对照表.md
```

### 素材只维护一处

1. 两本书都直接读取 figures 目录下的同一批 md，不复制。改一个人物文件，两本书都会变。
2. 运行一次 `python build_book.py`，同时生成两个 HTML，不会出现只更新了一本的情况。
3. 两本书对同一份 md 做不同的裁剪。《以人证道》保持现状；《以我见人》在生成时去掉"适用真题"一节。裁剪在脚本里完成，不改素材文件。
4. 人物名单和排序（FIGURE_META）两本书共用，新增人物只需登记一次。
5. 新书独有的"生活入口"写在对照表里，不写进人物 md，《以人证道》因此不受影响。对照表中的人名链接到书内对应的人物卡片。

## 三、总体结构

```
以我见人：从生活到素材的记叙文写作
├── 前言：记叙文里为什么要用素材，怎么用
├── 第一部分：写法工具箱（8 个模块）
├── 第二部分：典型题型场景库
├── 第三部分：素材入文
│   ├── 按入口类型分类的示范段落
│   └── 人物生活入口对照表
└── 第四部分：人物素材（复用现有素材库）
```

## 四、第一部分：写法工具箱

| 模块 | 一句话原理 | 大师示范 |
|------|-----------|---------|
| 1. 动词写人 | 一个准确的动词顶得上一串形容词 | 朱自清《背影》父亲爬月台的"攀""缩""微倾" |
| 2. 以物写情 | 情绪放在东西上，人不出面 | 归有光《项脊轩志》的枇杷树 |
| 3. 白描 | 只写看见的，不加修饰 | 张岱《湖心亭看雪》的"一痕""一点""一芥" |
| 4. 五感写细节 | 写声音、气味、味道，让读者在场 | 汪曾祺《端午的鸭蛋》"筷子头一扎下去，吱——红油就冒出来了" |
| 5. 一句话改变关系 | 一句对白就是情节的转折 | 鲁迅《故乡》闰土叫出的"老爷" |
| 6. 前后对照 | 同一个动作出现两次，中间的变化不用说 | 鲁迅《孔乙己》"排出九文大钱"与"摸出四文大钱" |
| 7. 以小见大 | 一件小事撑起一篇文章 | 鲁迅《一件小事》 |
| 8. 留白结尾 | 结尾停在事上，意思留给读者 | 鲁迅《社戏》"再没有吃到那夜似的好豆" |

每个模块包含：

1. **一句话原理**
2. **大师示范**：原文摘录和讲解。来源包括现有素材库人物（归有光、张岱、鲁迅），也包括朱自清、汪曾祺等课外名家
3. **学生场景迁移**：先给一道作文题和审题选材思路，再给一段核心片段，让读者看清"题目、生活事件、素材"三者怎样接上。半数以上模块的片段要带素材入文

## 五、第二部分：典型题型场景库

不收集真题。按低年级记叙文的常见命题方向自拟题型：

| 题型 | 典型题目 | 场景启发方向 | 可搭配的素材入口 |
|------|---------|-------------|----------------|
| 成长 | 那一次，我长大了 | 第一次一个人坐公交去外婆家 | 路过的故居、纪念馆 |
| 亲情 | 藏在＿＿里的爱 | 一个不起眼的日常习惯 | 外婆的中药与李时珍 |
| 尝试与挫折 | 一次有趣的尝试 | 跟爷爷学写毛笔字，重点写中间失败的几次 | 颜真卿的字帖 |
| 写人 | 我身边的＿＿ | 用一个反差细节写一个人 | 长辈讲的人物故事 |
| 景物与心情 | 那一片风景 | 同一个地方，两次去看到的不同 | 西湖边的于谦祠和岳飞墓 |
| 地方与风物 | 家乡的＿＿／一次旅行 | 一样吃的、一处老地方 | 当地的名人故居、碑刻 |

每类题型给出：

1. 题型特征和常见失分点
2. 2 到 3 个破题思路
3. 一个开头示范段

## 六、第三部分：素材入文

**示范段落。** 按入口类型（实地、读书、影视、长辈讲述、家里的一件东西、节令习俗）各写示范段落。每段后附说明：入口是什么，素材占了多少，呼应在哪里。示例见写作规范第十节的"素材入文示例"。

**人物生活入口对照表。** 为素材库中每位人物标注 1 到 2 个学生生活里真实可能碰到的入口，例如：

| 人物 | 生活入口 |
|------|---------|
| 于谦 | 杭州西湖于谦祠 |
| 鲁迅 | 上海鲁迅公园的墓、绍兴故居 |
| 李时珍 | 中药铺抓药 |
| 颜真卿 | 练字的字帖 |
| 郑板桥 | 家里挂的竹子画 |

对照表放在新书自己的文件里，不改动现有的人物 md。

## 七、书名

《以我见人：从生活到素材的记叙文写作》。与《以人证道》成对，一本写议论文，一本写记叙文。
