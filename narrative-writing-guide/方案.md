# 《以我见人：从生活到素材的记叙文写作》方案

## 一、背景与方向

现有的《以人证道》以人物素材服务议论文和半命题作文，逻辑是"题目 → 标签 → 人物"，用别人的故事证明一个观点。

六七年级的考试以记叙文为主（八年级起转向议论文），题目多围绕"自己"的生活。学生的问题通常不是没有经历，而是写出来像流水账。

本书为一个具体的孩子而写。读者画像见写作规范第零节，书里的家人、物件和经历都从画像里取，取不到的先问清楚再写，不写通用示范。

本书的方向：记叙文以"我"的经历为线，尽量多用人物素材。素材通过真实的生活入口进入文章，比如读书、纪录片、长辈的讲述、家里的一件东西。这样既不生硬，又能体现学生的知识面，形成得分点。

所有书稿都必须遵守 [写作规范](写作规范.md)。

## 二、产出形式与文件组织

**独立成书，与《以人证道》共用同一份人物素材。** 新书正文全部写成 md，方便手动修改，再由 build_book.py 生成 HTML。

### 文件结构

```
chinese-essay-figures/figures/          人物素材，两本书共用，只有这一份
narrative-writing-guide/
├── 方案.md、写作规范.md、真题题库.md     内部文档，不进入成书
└── book/
    ├── 前言.md
    └── 写法/01-动词写人.md ……            文件名前的序号决定顺序
```

### 素材只维护一处

1. 两本书都直接读取 figures 目录下的同一批 md，不复制。改一个人物文件，两本书都会变。
2. 运行一次 `python build_book.py`，同时生成两个 HTML，不会出现只更新了一本的情况。
3. 两本书对同一份 md 做不同的裁剪。《以人证道》保持现状；《以我见人》在生成时去掉"适用真题"一节。裁剪在脚本里完成，不改素材文件。
4. 人物名单和排序（FIGURE_META）两本书共用，新增人物只需登记一次。

## 三、总体结构

```
以我见人：从生活到素材的记叙文写作
├── 前言：这本书怎么用
├── 写法章节（每章一种写法）
└── 附录：人物素材（复用现有素材库）
```

原方案里的"典型题型场景库"和"素材入文"两部分不再单独成篇。题型训练已经由每章的三道真题和审题表承担；素材入文已经由每章的核心片段承担，入口包括读书、纪录片、长辈讲述、家里的东西。

每章包含：

1. **原理**：几句话说清这种写法怎么做
2. **大师示范**：多引原文，一处至少一整段；必要时加注释，交代读懂原文所需的背景
3. **学生场景迁移**：三道真题，审题与选材表，一段不少于 500 字的核心片段，讲解"这段是怎么写的"
4. **动手试试**：一个小练习

出题在先：先从真题题库选定三道题，再找能同时写进三道题的生活事件和素材，最后写片段。片段写完要回头核对，三道题的题眼在片段里都有着落。

## 五、真题

真题全部来自上海六七年级上学期期中考试，收在 [真题题库](真题题库.md)。一题只用一次，用过的标明章节。题库里的题都要用上，用不进已有章节的，就新增写法章节。

## 六、书名

《以我见人：从生活到素材的记叙文写作》。与《以人证道》成对，一本写议论文，一本写记叙文。
