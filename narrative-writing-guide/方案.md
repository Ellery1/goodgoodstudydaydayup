# 低年级记叙文写作指南：方案

## 一、背景与方向

现有的《以人证道》以人物素材服务议论文和半命题作文，逻辑是"题目 → 标签 → 人物"，用别人的故事证明一个观点。

七年级及以下的考试以记叙文为主，题目多围绕"自己"的生活，比如"一次有趣的尝试"。学生的问题通常不是没有经历，而是写出来像流水账。

本书的方向：记叙文以"我"的经历为线，但要尽量多用人物素材。素材通过真实的生活入口进入文章，比如扫墓、参观、读书、家里的一件东西。这样既不生硬，又能体现学生的知识面，形成得分点。素材库中于谦祠、鲁迅墓两段就是这种写法。

所有范文、示范段落都必须遵守 [写作规范](写作规范.md)。

## 二、产出形式

**独立成书，与《以人证道》共用人物素材，由 build_book.py 扩展生成第二个 HTML。**

理由：

1. 素材复用多。新书要带上人物素材正文，学生才能在一本书里查到可用的细节。两本书读同一份人物 md，改一处，两边同步。
2. 读者不同。《以人证道》面向中高考议论文，带真题解析；新书面向七年级及以下，不带真题，另有写法和题型两部分。合成一本，两类读者都要翻过一半与自己无关的内容。
3. 复用 build_book.py 现有的页面样式、侧边栏和阅读工具栏，不另写一套。

新书中的人物卡片去掉"适用真题"表格，换成该人物的"生活入口"（见第六节）。

## 三、总体结构

```
记叙文写作指南（低年级版）
├── 前言：记叙文里为什么要用素材，怎么用
├── 第一部分：写法工具箱（8 个模块）
├── 第二部分：典型题型场景库
├── 第三部分：素材入文
│   ├── 按入口类型分类的示范段落
│   └── 人物生活入口对照表
└── 第四部分：人物素材（复用现有素材库）
```

## 四、第一部分：写法工具箱

| 模块 | 一句话原理 | 大师示范 |
|------|-----------|---------|
| 1. 动词写人 | 一个准确的动词顶得上一串形容词 | 朱自清《背影》父亲爬月台的"攀""缩""微倾" |
| 2. 以物写情 | 情绪放在东西上，人不出面 | 归有光《项脊轩志》的枇杷树 |
| 3. 白描 | 只写看见的，不加修饰 | 张岱《湖心亭看雪》的"一痕""一点""一芥" |
| 4. 五感写细节 | 写声音、气味、味道，让读者在场 | 汪曾祺《端午的鸭蛋》"筷子头一扎下去，吱——红油就冒出来了" |
| 5. 一句话改变关系 | 一句对白就是情节的转折 | 鲁迅《故乡》闰土叫出的"老爷" |
| 6. 前后对照 | 同一个动作出现两次，中间的变化不用说 | 鲁迅《孔乙己》"排出九文大钱"与"摸出四文大钱" |
| 7. 以小见大 | 一件小事撑起一篇文章 | 鲁迅《一件小事》 |
| 8. 留白结尾 | 结尾停在事上，意思留给读者 | 鲁迅《社戏》"再没有吃到那夜似的好豆" |

每个模块包含：

1. **一句话原理**
2. **大师示范**：原文摘录和讲解。来源包括现有素材库人物（归有光、张岱、鲁迅），也包括朱自清、汪曾祺等课外名家
3. **学生场景迁移**：一段 200 字左右的示范段落。半数以上模块的示范段要带素材入文

## 五、第二部分：典型题型场景库

不收集真题。按低年级记叙文的常见命题方向自拟题型：

| 题型 | 典型题目 | 场景启发方向 | 可搭配的素材入口 |
|------|---------|-------------|----------------|
| 成长 | 那一次，我长大了 | 第一次一个人坐公交去外婆家 | 路过的故居、纪念馆 |
| 亲情 | 藏在＿＿里的爱 | 一个不起眼的日常习惯 | 外婆的中药与李时珍 |
| 尝试与挫折 | 一次有趣的尝试 | 跟爷爷学写毛笔字，重点写中间失败的几次 | 颜真卿的字帖 |
| 写人 | 我身边的＿＿ | 用一个反差细节写一个人 | 长辈讲的人物故事 |
| 景物与心情 | 那一片风景 | 同一个地方，两次去看到的不同 | 西湖边的于谦祠和岳飞墓 |
| 地方与风物 | 家乡的＿＿／一次旅行 | 一样吃的、一处老地方 | 当地的名人故居、碑刻 |

每类题型给出：

1. 题型特征和常见失分点
2. 2 到 3 个破题思路
3. 一个开头示范段

## 六、第三部分：素材入文

**示范段落。** 按入口类型（实地、读书、影视、长辈讲述、家里的一件东西、节令习俗）各写示范段落。每段后附说明：入口是什么，素材占了多少，呼应在哪里。示例见写作规范第十节的"素材入文示例"。

**人物生活入口对照表。** 为素材库中每位人物标注 1 到 2 个学生生活里真实可能碰到的入口，例如：

| 人物 | 生活入口 |
|------|---------|
| 于谦 | 杭州西湖于谦祠 |
| 鲁迅 | 上海鲁迅公园的墓、绍兴故居 |
| 李时珍 | 中药铺抓药 |
| 颜真卿 | 练字的字帖 |
| 郑板桥 | 家里挂的竹子画 |

对照表放在新书自己的文件里，不改动现有的人物 md。

## 七、待确认事项

1. **现有素材中第一人称段落是否按新规范修改。** 于谦祠一段用了破折号，结尾"我想告诉他……"属于写作规范禁止的"对着古人说话"。新书如果拿这些段落当示范，需要先改。
2. **目标年级和字数。** 只到七年级，还是包括小学高年级；示范段和范文按 500 字还是 600 字的考场要求来写。
3. **书名。**
