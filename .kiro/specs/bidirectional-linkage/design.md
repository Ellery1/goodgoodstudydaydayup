# 设计文档：素材库双向联系与标签体系重构

## 一、现状分析

### 1.1 当前数据结构

```
figures/人物.md        → 一句话定位 / 热门指数 / 适配标签 / 核心素材(2-3段故事)
examples/初中/题.md    → 题目 / 审题方向 / 可用人物素材(人物名 + 一句话理由)
examples/高中/题.md    → 同上
build_book.py          → FIGURE_META 字典(人物→标签列表，用于HTML生成)
```

### 1.2 已有联系

- **题目 → 人物**：每道真题末尾的"可用人物素材"段落（单向）
- **人物 → 题目**：❌ 尚未建立

### 1.3 标签问题

现有约30个标签，分布如下：

| 标签 | 出现次数 | 问题 |
|------|---------|------|
| 坚持 | 10+ | 太空泛——司马迁的坚持≠蒲松龄的坚持≠玄奘的坚持 |
| 孤独 | 10+ | 陀思妥耶夫斯基的孤独≠特斯拉的孤独≠卡夫卡的孤独 |
| 突破 | 8+ | 含义过于宽泛，几乎人人可贴 |
| 勇气 | 6+ | 于谦的勇气和陈不占的勇气完全不是一回事 |
| 创新 | 6+ | 特斯拉的创新≠黄道婆的创新≠墨子的创新 |
| 智慧 | 6+ | 最没有辨识度的万能标签 |

**核心问题**：当你搜索"坚持"，返回10个人物，无法判断哪个人物适合哪道具体的题。标签的意义在于帮助检索和匹配，但当标签太抽象、太重叠时，它就失去了区分能力。

---

## 二、设计方案

### 2.1 核心思路：用"适用场景句"替代空泛标签

**放弃**：试图用2-3个抽象词语概括一个人物的适用性  
**改为**：为每个人物列出"在什么题目方向上可以用、怎么用"的**具体场景**

#### 2.1.1 人物文件新增 `### 适用真题` 段落

在每个人物 `.md` 文件末尾，新增一个段落，格式如下：

```markdown
---

### 适用真题

| 真题 | 切入角度 |
|------|---------|
| 全国I卷-2026-高考 | 对"生死"的理解：从避死到"死有重于泰山"的权衡 |
| 全国II卷-2026-高考 | 极辱之中"其体未失"，《史记》终成 |
| 天津卷-2024-高考 | 被宫刑定义为罪人，用《史记》自定义为史家 |
```

**说明**：
- "切入角度"就是真题那边已经写好的那句简短说明，直接复用
- **每人最多列3个最合适的真题**，挑匹配度最高的，不贪多
- build_book.py 渲染 HTML 时将真题名转为站内锚点跳转链接
- 这个表格直接回答了"这个人物能用在哪些题上、怎么切入"，比空泛标签有用100倍

#### 2.1.2 标签体系的改造

**保留**标签，但做两层改造：

**第一层：缩减为"大类标签"（仅用于粗筛和HTML侧边栏索引）**

将现有30+标签精简为约12个**互斥性更强**的大类：

| 大类标签 | 含义边界 | 典型人物 |
|---------|---------|---------|
| 家国担当 | 个人命运与民族/国家/社会命运的交织 | 于谦、谭嗣同、辛弃疾、范仲淹 |
| 绝境重生 | 苦难/极端处境中不屈，且最终有成果产出 | 司马迁、陀思妥耶夫斯基、塞万提斯 |
| 求真实证 | 以实践/实验/亲历对抗权威和空谈 | 维萨里、沈括、李时珍、郦道元 |
| 开拓创造 | 发明新事物/新方法/新路径 | 特斯拉、达·芬奇、黄道婆、墨子 |
| 文以载道 | 以写作/艺术为工具，承载精神使命 | 鲁迅、契诃夫、归有光、巴赫 |
| 克己奉献 | 牺牲个人利益服务他人/公共 | 南丁格尔、特斯拉、玄奘 |
| 知音相惜 | 人与人之间的理解、善意、成全 | 伯牙与钟子期、顾荣 |
| 独行不改 | 不被理解、不合时宜却不改初衷 | 卡夫卡、蒲松龄、张岱 |
| 气节清白 | 在权力/利益面前不变节，以死明志 | 于谦、齐国太史兄弟、颜真卿、李定国 |
| 少年突围 | 出身低微/逆境起步，凭自身改命 | 狄青、班超、祖逖 |
| 日常见深 | 在平凡细微处见真情/哲理 | 归有光、泰戈尔、袁枚、顾荣 |
| 时间耐力 | 长期坚持、大器晚成、水磨工夫 | 蒲松龄、左宗棠、李时珍、玄奘 |

**注意**：一个人物可以有1-2个大类标签，但不超过2个。强制限制数量倒逼精准。

**第二层：废弃每段素材末尾的"可适配标签"行**

现在每个故事段落末尾都有 `**可适配标签**：突破、孤独` 这样的行。这些行：
- 重复且空泛
- 和顶部"适配标签"高度重叠
- 对实际使用帮助极小

**方案**：删除所有段落末尾的"可适配标签"行。每个人物的适用性由两个东西来承载：
1. 顶部的1-2个大类标签（粗筛）
2. 末尾的"适用真题"表格（精确匹配）

#### 2.1.3 build_book.py 的改动

- `FIGURE_META` 中的标签列表改为新的大类标签（每人1-2个）
- HTML生成时，侧边栏"标签索引"用新大类标签
- 真题卡片中的"可用人物素材"格式不变
- 人物卡片末尾追加渲染"适用真题"表格

---

### 2.2 题目 → 人物 匹配度复核

在执行上述改造时，逐题复核每道真题的人物匹配。复核标准：

1. **该人物的哪段具体素材**能切入这道题？如果只能靠抽象标签强行关联，判为不合适
2. **切入角度句**是否准确？是否用了素材中实际存在的细节？
3. 如果不合适，优先从现有41人中换人；如果确实无人可用，标注 `⚠️ 待补充` 并说明缺什么类型的人物

**复核结果输出格式**：

对于每个需要调整的真题，列出：
```
文件名
  ❌ 原推荐：人物A（原因：为什么不合适）
  ✅ 改为：人物B（切入角度：xxx）
  或
  ⚠️ 空缺，需要补充：xxx类型的人物
```

---

### 2.3 执行顺序

```
Phase 1: 标签体系重构
  1.1 确定12个大类标签的最终清单和每个人物的归属
  1.2 更新 build_book.py 中的 FIGURE_META
  1.3 删除每个人物md中段落末尾的"可适配标签"行
  1.4 更新每个人物md顶部的"适配标签"为新大类标签

Phase 2: 题目→人物 复核
  2.1 逐题检查55道真题的人物匹配，产出调整清单
  2.2 执行调整（换人或标注空缺）

Phase 3: 人物→题目 反向联系
  3.1 根据所有真题的最终"可用人物素材"，为每个人物生成"适用真题"表格
  3.2 追加到每个人物md末尾

Phase 4: 验证
  4.1 运行 build_book.py 确认HTML生成正常
  4.2 检查双向联系的一致性（题目提到的人物，人物也指向该题目）
```

## 四、预期效果

| 改动前 | 改动后 |
|--------|--------|
| 人物标签空泛重叠，搜"坚持"出10人，无法区分 | 12个大类标签互斥性强，粗筛有效 |
| 人物→题目无联系，不知道这个人能用在哪 | 每个人物末尾明确列出适用真题+切入角度 |
| 段落末尾标签与顶部标签重复，占空间无实用 | 删除，由"适用真题"表格承担精确匹配 |
| 题目→人物匹配未经复核 | 逐题复核，不合适的换人或标注空缺 |

## 五、风险与注意事项

1. **HTML锚点跳转**：人物md中的真题名在build_book.py渲染时需要转为站内锚点链接（跳转到对应真题卡片）。真题卡片的id命名规则需与此一致。

2. **标签精简可能丢失信息**：部分人物的多面性（如特斯拉同时有"开拓创造"和"克己奉献"）通过限制最多2个标签来保留，不会超出。如果某人物的适用面确实极宽（如司马迁），由"适用真题"表格来承载。

3. **新增真题时的维护**：以后每新增一道真题，需要同步更新相关人物的"适用真题"表格。可以考虑后续写一个脚本自动从真题中提取并同步。
