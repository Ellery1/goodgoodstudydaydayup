### 关于这本书

本书精选了41位中外历史人物，为每人撰写了2-3段深度素材，每段400-800字，全书人物素材合计约七万字。同时收录了 55 道中高考作文真题（覆盖2023-2026年全国主要考区），逐题标注审题方向和推荐人物。

语文考场上看到作文题目的那一刻，你只有很少的时间决定"写什么内容"。本书的设计期望，就是让这个决策变得快而精准。

为此，本书在人物与真题之间建立了双向联系：每道真题标注了最适合的2-3位人物及其切入角度；每个人物也反向标注了自己最适合的真题。从题找人，或从人找题，都是最短路径。

逻辑链条是：**题目 → 标签 → 人物**。

以及还应当考虑到**复用性**：同一个人物素材，通过不同的切入角度，完全可以适配多道不同的题目。你需要把少量人物吃透，然后在考场上用不同的角度把他们"旋转"到大部分题目上去。

### 标签体系

12个大类标签，每个人物有1-2个，用于快速定位：

| 标签 | 含义 | 典型人物 |
|------|------|---------|
| 家国担当 | 个人命运与民族/国家命运交织 | 于谦、谭嗣同、辛弃疾 |
| 绝境重生 | 极端处境中不屈且有成果产出 | 司马迁、陀思妥耶夫斯基 |
| 求真实证 | 以实践/实验对抗权威和空谈 | 维萨里、沈括、李时珍 |
| 开拓创造 | 发明新事物/新方法/新路径 | 特斯拉、达·芬奇、黄道婆 |
| 文以载道 | 以写作/艺术承载精神使命 | 鲁迅、契诃夫、归有光 |
| 克己奉献 | 牺牲个人利益服务他人或公共 | 南丁格尔、玄奘 |
| 知音相惜 | 人与人之间的理解、善意、成全 | 伯牙与钟子期、顾荣 |
| 独行不改 | 不被理解却不改初衷 | 卡夫卡、蒲松龄、张岱 |
| 气节清白 | 在权力/利益面前不变节 | 齐国太史兄弟、颜真卿 |
| 少年突围 | 出身低微/逆境起步，凭自身改命 | 狄青、祖逖 |
| 日常见深 | 在平凡细微处见真情/哲理 | 归有光、泰戈尔、袁枚 |
| 时间耐力 | 长期坚持、大器晚成 | 蒲松龄、左宗棠、李时珍 |

### 关于史料

本书所有人物素材均有史料支撑。正史记载者注明出处，野史或民间传说也有明确说明，不做无中生有的虚构。本书的目的不光是为了应试，也希望具备"拓展课外知识"的功能。
